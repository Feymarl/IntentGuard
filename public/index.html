🛡️ IntentGuard

The bouncer for NEAR Intents swaps — vets the token you're about to buy (honeypot, tax, owner, liquidity) and blocks the swap if it's a trap.

Dry quotes only · No wallet · No funds move · Built at NEAR HACKATHON 2026

Try the demo cases:

How it works: the gate vets the destination token before quoting. BLOCK → swap refused, no quote fetched. RISKY → quote shown with the risks; proceeding needs an explicit acknowledgment. SAFE → quote shown. Quotes come from the NEAR Intents 1Click API with dry: true — real solver pricing, no deposit address, nothing is ever executed here. Source: MintGuard is our other NEAR Hackathon project (it vets contracts you mint; IntentGuard vets tokens you buy).
